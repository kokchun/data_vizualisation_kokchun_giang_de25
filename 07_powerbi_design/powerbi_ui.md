# In-class Exercise - Polish Power BI Report

We are going to polish the bike order report.

## 1. Polish Report

Your boss is satisfied with the functionality of your report but would like you to improve the appearance of the report. Work on the following points:

- on the bar chart for no. of order by state, use conditional formatting with gradient to highlight the bars with high values
- on the same bar chart, add the store city data so that drilldown function is enabled
- configure the data format of the metrics on the cards so that the metrics have the format like the example report below
- add a button to clear all slicers
- improve the design of the report with padding, rounded corners, shadow and alignment
